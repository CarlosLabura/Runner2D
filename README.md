# Simple 2D Runner
This is a simple project focused on developing the mechanics of an infinite 2d Runner.

The idea is to keep alive the most time you can, avoiding the obstacles and getting the best score you can get.

## This project includes
- Infinite obstacle generation, with easy implemention of new ones.
- Player whos able to jump, with keyboard and mouse implementation.
- UI and HUD elements like points and game over.
- Scrolling background and post processing for a better yet simplistic look.
